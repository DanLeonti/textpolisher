# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could put users at
risk.

Email **leonti174@gmail.com** with:

- the affected version and platform;
- clear reproduction steps;
- the potential impact; and
- any suggested mitigation.

You should receive an acknowledgement within seven days. Please allow time for
a fix and release before publicly disclosing the issue.

## Scope

Security reports may cover the macOS, Windows, and iOS apps, the update
mechanism, installers, and the TextPolisher website.
